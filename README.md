# DECO Design Portfolio Evidence

This repository contains supporting evidence for my individual DECO Design Portfolio. It is organised by portfolio entries E1-E4.

## Authorship and context

- **Team artefacts** are identified separately from my individual work. They show the shared project context and outcomes that informed my contribution.
- **Individual synthesis and planning** refers to how I connected team research, identified assumptions, structured validation activities, and responded to feedback.
- The handwritten reasoning diagrams are **retrospective reconstructions / refined representations** created to communicate my design reasoning clearly. They are not presented as original contemporaneous Week 5 notes.
